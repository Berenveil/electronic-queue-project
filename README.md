## Project Goal

Веб-система электронной очереди для поликлиники, которая позволяет пациентам получать электронные талоны, отслеживать статус кабинетов в поликлинике («ожидает» / «вызван») и автоматически рассчитывать среднее время ожидания, а также предоставляет администратору инструменты управления кабинетами врачей и просмотра статистики нагрузки. Система направлена на сокращение времени ожидания пациентов, упрощение работы регистратуры и повышение эффективности работы врачей.

## Инструкция по запуску

### Требования

- **.NET SDK 10**
- **Git**

### Клонирование

```bash
git clone https://github.com/Berenveil/electronic-queue-project.git
cd electronic-queue-project
```

### Установка и запуск

1. Восстановите зависимости:

   ```bash
   dotnet restore
   ```

2. Запустите проект из корневой папки репозитория:

   ```bash
   dotnet run --project src/App
   ```

3. Откройте сайт в браузере:

   **Локальный сервер: [http://localhost:5207](http://localhost:5207)**

Для остановки сервера нажмите `Ctrl+C` в терминале.

> При первом запуске база SQLite создаётся автоматически, применяются миграции и загружаются начальные данные. Файлы базы данных исключены из Git через `.gitignore`.

## Архитектура проекта

Приложение состоит из трёх основных частей:

- **Интерфейс:** HTML, CSS и JavaScript — страницы сайта и взаимодействие с пользователем.
- **Сервер:** C# и ASP.NET Core — обработка запросов и API.
- **База данных:** SQLite и Entity Framework Core — хранение данных и работа с ними.

Браузер получает страницы и отправляет запросы к API. Сервер обращается к базе через Entity Framework Core и возвращает данные интерфейсу.

| Путь | Назначение |
| --- | --- |
| `src/App/Program.cs` | Запуск приложения, подключение базы данных и API |
| `src/App/Data/` | Контекст базы данных, модели и начальные данные |
| `src/App/Migrations/` | Миграции структуры базы данных |
| `src/App/Features/Tickets/` | Заготовка модуля электронных талонов |
| `src/App/wwwroot/` | Страница сайта, стили, JavaScript и изображения |
| `src/App/appsettings.json` | Настройки приложения и подключения к базе |
| `src/App/Properties/launchSettings.json` | Профили запуска и адрес локального сервера |

## Текущее состояние

Реализованы каталог врачей, просмотр услуг и цен, форма записи с проверкой данных пациента и загрузка информации из базы.

Выбор времени, сохранение записи, выдача талонов, управление очередью и инструменты администратора находятся в разработке.
