# Фотографии врачей

Фотографии уже скопированы в подпапки `man` (11 файлов) и `woman` (13 файлов).
Внутри каждой группы снимки назначены по возрастанию ID врача, без повторений.
Все 24 карточки используют отдельные изображения.

1. Чтобы заменить фотографию, положите новый файл в эту папку или её подпапку.
   Подойдут JPG, JPEG, PNG и WebP.
2. В начале `wwwroot/js/site.js` измените путь в объекте `doctorPhotos`.
   Слева указывается ID врача из базы, справа — путь относительно этой папки:

   ```js
   const doctorPhotos = {
       1: "man/1.png",       // Иванов Артём Сергеевич
       2: "woman/1.png",     // Смирнова Анна Дмитриевна
       // Остальные записи оставьте на месте.
   };
   ```

3. Сохраните `site.js` и обновите страницу запущенного сайта.

Указывайте только пути к существующим фотографиям.
Имена файлов чувствительны к регистру: `Ivanov.JPG` и `ivanov.jpg` — разные имена.
Изменение расширения не конвертирует изображение: для PNG укажите `.png`.
Фото автоматически обрезается по размеру блока без искажения пропорций.
Если файл не указан или не загрузился, карточка показывает заглушку «Фото врача».
Менять HTML отдельно для каждого врача не нужно.
